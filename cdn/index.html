CDN

Aset yang sama, lebih dekat ke pengguna. Lihat edge CDN mengambil salinan dari origin, lalu melayani request berikutnya.

Minta aset dua kali, lalu pindah lokasi untuk membandingkan edge.

Belum ada requestOrigin diakses 0×

Lebih dekat

CDN mengarahkan pengguna ke edge yang dekat secara jaringan, tempat salinan aset disimpan.

Hit

Jika aset ada di edge, response langsung kembali ke pengguna tanpa mengakses origin.

Miss

Jika belum ada, edge mengambil aset dari origin dan menyimpan salinannya untuk request berikutnya.

Model dua wilayah untuk satu aset yang boleh di-cache. Routing dan waktu animasi disederhanakan; TTL, validasi ulang, dan tier cache tidak disimulasikan. Purge menghapus salinan di kedua edge.
